# Publishing Notes

Recommended public positioning:

- Name it as a `DING fork` or `DING-based folder preview extension`.
- Do not present it as official DING.
- Keep upstream attribution visible in the root documentation.

Recommended release setup:

1. Publish this repository as the GPL extension/fork.
2. If you build a separate desktop-organizer product, keep it in a separate repository or clearly separated component.
3. Treat this DING-derived part as the optional extension feature layer.

Recommended files to keep in the root:

- `README.md`
- `COPYING`
- `ATTRIBUTION.md`
- `CHANGES.md`
- `PUBLISHING.md`

Recommended release note wording:

`Desktop Organizer Folders is a GPLv3 fork of DING that adds preview-style desktop folders and a single-click folder preview popover.`
