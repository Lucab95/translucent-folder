# Changes

Main changes relative to upstream DING:

1. Desktop folders render as preview tiles instead of plain folder icons.
2. Folder tiles show up to 4 child-item icons.
3. Single click opens a folder preview popover.
4. Double click keeps the normal folder-open behavior.
5. Clicking outside closes the preview popover.
6. Popover styling hooks were added for the folder-preview UI.

- `ding-transparent-folders@lucabrugaletta.com/app/stylesheet.css`
